# Car Rental Management System

A web-based car rental system where customers can browse and book cars, and an admin can view bookings and revenue.

## Features
- Browse available cars with photos, category, price per day and seats
- Sign up and log in with email and password validation
- Book a car by choosing pickup and return dates, with the total cost calculated
- Admin dashboard showing total cars, available cars, bookings made and total revenue
- Admin bookings table where bookings can be deleted
- Dark mode
  
## Notes
This is a front-end project. Users and bookings are saved in the browser using localStorage, so there is no backend or database. The login is a demo and does not check passwords against a server.

## Built with
HTML · CSS · JavaScript

## Project structure
- `index.html`: home page
- `car.html`: car details
- `login.html`: login
- `admin.html`: admin dashboard
- `css/`: styles
- `js/`: scripts for cars, authentication and admin
- `images/`: car photos

## How to run
1. Download or clone this repository
2. Open `index.html` in your browser
